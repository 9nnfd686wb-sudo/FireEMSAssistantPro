# Summary Engine 仕様

## 目的

回答内容から消防指令員・救急隊向けの申し送り文章を自動生成する。

## 役割

- SummaryEngine は純粋なロジックのみを担当する
- DOM 操作禁止
- `window` 操作禁止
- `alert` 禁止
- `localStorage` 操作禁止

## 入力

- `protocolId`: string
- `answers`: object
- `redFlags`: array
- `urgency`: object

## 出力

```json
{
  "summary": "突然発症の胸痛です。\n左肩へ放散しています。\n冷汗があります。\n呼吸困難があります。\n意識障害があります。\n疼痛は10/10です。\n緊急度はLEVEL2（高）です。"
}
```

## 文章生成ルール

- 自然な日本語で出力する
- 存在しない情報は出力しない
- 回答がある項目のみ文章化する
- 改行は `\n` で維持する
- `redFlags` はラベルをそのまま使用する
- `urgency` は `LEVELX（label）` の形式でまとめる

### 生成パターン

- `突然発症` → `突然発症の胸痛です。`
- `冷汗` → `冷汗があります。`
- `呼吸困難` → `呼吸困難があります。`
- `意識障害` → `意識障害があります。`
- `放散痛` → `{回答}へ放散しています。`
- `疼痛` → `疼痛は{回答}です。`
- `urgency` → `緊急度はLEVEL{n}（{label}）です。`

## 画面表示

- `pages/result.html` の `📝 申し送り` カードに表示
- コピー用ボタンを配置
- コピー成功時に `申し送りをコピーしました` を3秒表示

## テスト項目

- 回答が少ない場合
- 回答が多い場合
- RedFlagなし
- LEVEL1〜LEVEL4
- 未入力項目
